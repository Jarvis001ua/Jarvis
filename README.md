# Джарвис Атмосфера

Голосовой ассистент на Python: распознаёт команды (ru/en), отвечает голосом
и управляет «атмосферой» комнаты — режимами освещения, музыкой и звуками.

## Возможности

- Приветствие, время, дата, статус
- Режимы атмосферы: **фокус**, **релакс**, **ночь**, **вечеринка**
- Управление светом («светлее» / «темнее») и музыкой («включи/выключи музыку»)
- Текстовый режим для работы без микрофона
- Ядро команд покрыто тестами и не зависит от аудио-библиотек

## Установка

```bash
pip install -r requirements.txt
```

Для распознавания речи в Google нужно интернет-соединение; микрофон — через
PyAudio (на Linux предварительно: `sudo apt install portaudio19-dev`).

## Запуск

```bash
# голосовой режим (микрофон)
python -m jarvis_atmosphere

# текстовый режим (без микрофона)
python -m jarvis_atmosphere --text

# одна команда без цикла
python -m jarvis_atmosphere "включи режим ночь"
```

## Примеры команд

| Команда | Действие |
| --- | --- |
| «Джарвис, который час?» | Текущее время |
| «Включи режим релакс» | Сцена: приглушённый свет, ambient, звук дождя |
| «Режим ночь» / «Режим фокус» | Переключение сцены |
| «Приглуши свет» / «Светлее» | Регулировка освещения |
| «Включи музыку» / «Выключи музыку» | Управление музыкой |
| «Как дела?» / «Статус» | Состояние атмосферы |
| «Отбой» | Завершение работы |

## Структура

```
jarvis_atmosphere/
  __main__.py       # точка входа, циклы голосового и текстового режима
  intents.py        # распознавание намерений по ключевым словам (ru/en)
  actions.py        # выполнение команд и состояние атмосферы
  config.py         # сцены и настройки
  speech_input.py   # микрофон (SpeechRecognition), опционально
  speech_output.py  # синтез речи (pyttsx3), опционально
tests/              # pytest: намерения, действия, цикл обработки
```

## Расширение

Новая команда = пара строк: ключевые слова в `KEYWORDS`
(`jarvis_atmosphere/intents.py`) и ветка в `execute`
(`jarvis_atmosphere/actions.py`). Сцены настраиваются в `config.py`.

## Модуль «Заказы» (монитор фриланса)

Автоматический поиск заказов по публичным RSS-лентам, автогенерация
черновиков откликов, окно настроек с кошельком и аккаунтами,
автозапуск по расписанию.

```bash
python -m jarvis_atmosphere.jobs --once      # один опрос источников
python -m jarvis_atmosphere.jobs --auto      # авто-режим (опрос по интервалу)
python -m jarvis_atmosphere.jobs --settings  # настройки в терминале
python -m jarvis_atmosphere.jobs --gui       # окно настроек и монитора
python -m jarvis_atmosphere.jobs --tasks     # список задач на выполнение
```

### Выполнение задач

В окне программы есть вкладка «Задачи (выполнение)» (на телефоне — раздел
«Задачи»): очередь принятых заказов со статусами «новая → в работе →
на проверке → выполнено», редактор текста работы и экспорт готового
файла результата в `~/.jarvis_atmosphere/results/`. Готовый файл вы
отправляете заказчику вручную через биржу.

- **Настройки**: `~/.jarvis_atmosphere/settings.json` — адрес кошелька,
  логины аккаунтов, ключевые слова, бюджет, навыки, интервал опроса,
  время автозапуска (ЧЧ:ММ).
- **Пароли** хранятся только в системном хранилище ОС (keyring:
  Windows Credential Manager / macOS Keychain / Secret Service) и
  привязываются к аккаунтам при каждом запуске. В файлах проекта их нет.
- **Черновики** откликов сохраняются в `~/.jarvis_atmosphere/drafts/`.
  Отправка отклика и приём оплаты всегда выполняются человеком: Джарвис
  готовит текст, вы сами отправляете его на площадке.
- Источники по умолчанию: fl.ru и Habr Freelance (редактируются в настройках).

## Версия для Android (Termux + браузер)

На телефоне (например, Motorola Moto G24 Power) программа запускается через
Termux и открывается как веб-страница в браузере.

1. Установите **Termux** (из F-Droid: https://f-droid.org/packages/com.termux/)
2. В Termux скачайте проект и распакуйте, затем:
   ```bash
   cd Jarvis-Atmosphere
   bash termux_setup.sh
   python -m jarvis_atmosphere.mobile
   ```
3. Откройте в браузере телефона: **http://127.0.0.1:8080**

Интерфейс: ассистент (текстовые команды), монитор заказов с авто-режимом,
задачи на выполнение, настройки (кошелёк, аккаунты, бюджет, расписание).
Пароли на Android не сохраняются — вход на площадки делайте вручную.
