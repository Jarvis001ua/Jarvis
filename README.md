# Джарвис Атмосфера

Голосовой ассистент на Python: распознаёт команды (ru/en), отвечает голосом
и управляет «атмосферой» комнаты — режимами освещения, музыкой и звуками.

## Возможности

- Приветствие, время, дата, статус
- Режимы атмосферы: **фокус**, **релакс**, **ночь**, **вечеринка**
- Управление светом («светлее» / «темнее») и музыкой («включи/выключи музыку»)
- Текстовый режим для работы без микрофона
- Ядро команд покрыто тестами и не зависит от аудио-библиотек

## Установка

```bash
pip install -r requirements.txt
```

Для распознавания речи в Google нужно интернет-соединение; микрофон — через
PyAudio (на Linux предварительно: `sudo apt install portaudio19-dev`).

## Запуск

```bash
# голосовой режим (микрофон)
python -m jarvis_atmosphere

# текстовый режим (без микрофона)
python -m jarvis_atmosphere --text

# одна команда без цикла
python -m jarvis_atmosphere "включи режим ночь"
```

## Примеры команд

| Команда | Действие |
| --- | --- |
| «Джарвис, который час?» | Текущее время |
| «Включи режим релакс» | Сцена: приглушённый свет, ambient, звук дождя |
| «Режим ночь» / «Режим фокус» | Переключение сцены |
| «Приглуши свет» / «Светлее» | Регулировка освещения |
| «Включи музыку» / «Выключи музыку» | Управление музыкой |
| «Как дела?» / «Статус» | Состояние атмосферы |
| «Отбой» | Завершение работы |

## Структура

```
jarvis_atmosphere/
  __main__.py       # точка входа, циклы голосового и текстового режима
  intents.py        # распознавание намерений по ключевым словам (ru/en)
  actions.py        # выполнение команд и состояние атмосферы
  config.py         # сцены и настройки
  speech_input.py   # микрофон (SpeechRecognition), опционально
  speech_output.py  # синтез речи (pyttsx3), опционально
tests/              # pytest: намерения, действия, цикл обработки
```

## Расширение

Новая команда = пара строк: ключевые слова в `KEYWORDS`
(`jarvis_atmosphere/intents.py`) и ветка в `execute`
(`jarvis_atmosphere/actions.py`). Сцены настраиваются в `config.py`.
